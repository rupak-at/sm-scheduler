# Roboto

The Latin variable-weight normal font is vendored from
`@fontsource-variable/roboto` version 5.3.0.
Its source package is [Fontsource Roboto](https://fontsource.org/fonts/roboto).

Keep `LICENSE.txt` with this asset. Next.js loads it through `next/font/local`.
Additional scripts or italics should be added deliberately when needed.

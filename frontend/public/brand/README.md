# Social Scheduler logo files

- `social-scheduler-icon.svg`: editable vector app icon.
- `social-scheduler-icon-512.png`: 512 × 512 transparent-corner PNG for upload forms.
- `social-scheduler-icon-1024.png`: 1024 × 1024 PNG for TikTok's app icon upload.
- `social-scheduler-logo-kit.zip`: all three image files packaged for download.

The mark is original project artwork. Its dark background is `#27272a` and its route
and endpoint are white. The live wordmark uses the locally hosted Roboto font; see
`frontend/src/fonts/LICENSE.txt` for that font's license.
